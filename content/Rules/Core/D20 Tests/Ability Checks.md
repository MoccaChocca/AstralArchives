An ability check is a type of [[D20 Tests|D20 Test]] used to determine whether a creature succeeds at a task when the outcome is uncertain.  

The DM calls for an ability check when a creature attempts something that has a chance of failure. The DM chooses the ability that applies to the check and sets the DC. The higher the DC, the harder the task.

#### Skills
Each skill is associated with an ability. When a creature makes an ability check using a skill (referred to as a skill check), the check is written with the ability first, followed by the skill in parentheses.  

For example, a character [[Rules/Core/Movement/Movement|climbing]] a cliff might make a [[Strength|Strength (Athletics)]] check, while a character recalling magical lore might make an [[Intelligence|Intelligence (Arcana)]] check.  

The DM determines which skill, if any, applies to an ability check.

#### Tools  
A tool can also apply to an ability check if the creature is using that tool to attempt the task. If the creature is proficient with the tool, it adds its [[proficiency bonus]] to the check.  
  
For example, a character picking a lock might make a [[Dexterity]] check using thieves’ tools.
