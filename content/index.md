## Summary

The purpose of the Archives is to provide a single space for rules and content to be found. This enables quick lookup for up to date and relevant rules. This also enables the complete customisation for the rules that we decide to play with. 

All content is a work in progress. There are several changes we are looking to put in, including a change to our chose site host. 

If you have any suggestions or feedback on what you would like to see, please let me know!

The below is already in the pipeline
- A "Flag for review" button so that you can report a page that may be incorrect or require updates
- A change in themes and styles so it doesn't suck
- The possibility of a built in character creator. Or a character creator that is built off this ruleset. 
- Tables. Spell tables for spell lists etc.
- Adding in specific setting information for topics. (Can also create multiple settings...)
